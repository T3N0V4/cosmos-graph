# Cosmos Graph

Cosmos Graph adds an animated cosmic background to Obsidian's global and local Graph View. It renders ambient stars, constellation-style connections, parallax motion, shooting stars, planets, galaxies, and click effects behind the graph.

## Features

- Animated star field for Graph View and Local Graph View.
- Configurable particle density, color, brightness, movement, and connections.
- Mouse glow and mouse repulsion effects.
- Optional click effects with radial, directional, and gravity-style bursts.
- Background layers with parallax and subtle drifting stars.
- A settings tab for tuning visuals and performance.
- Performance warnings when expensive visual settings are pushed very high.

## Usage

1. Enable the plugin in Obsidian.
2. Open Graph View or Local Graph View.
3. Use **Settings -> Community plugins -> Cosmos Graph** to customize the visual effects.
4. Use the ribbon icon or command palette entry **Open Cosmos Control** to open the control view.

## Performance Notes

Cosmos Graph is visual and animation-heavy. If your graph or vault is large, start with lower particle counts, shorter connection distances, and fewer max connections per particle.
